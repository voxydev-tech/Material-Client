# Material Client

Настольный Minecraft-лаунчер для Windows 10/11 на Kotlin + Compose Desktop (Material 3).

## Что уже работает

- Material 3 UI, акцентные цвета, свой шрифт, полный русский и английский интерфейс (Настройки → Язык интерфейса).
- Экземпляры: создание, удаление, у каждого своя папка игры `~/.material-client/instances/<название>`.
- Установка Minecraft с официальных серверов Mojang: клиент, библиотеки, ресурсы, natives, проверка SHA-1.
- Загрузчики модов: **Forge** и **NeoForge** ставятся официальными установщиками, **Fabric** и **Quilt** — по профилю
  с их серверов метаданных, **OptiFine** — сборкой из официального установщика (патчер OptiFine + launchwrapper).
  Для каждого экземпляра запускается именно установленный профиль загрузчика.
- Запуск игры по JSON версии (аргументы, правила, `inheritsFrom`, подстановки), офлайн-аккаунты.
  Вывод игры пишется в `launcher-output.log` в папке экземпляра.
- Java подбирается и скачивается автоматически (см. раздел «Java» ниже), память и JVM-аргументы настраиваются
  для всех экземпляров сразу и для каждого отдельно.
- Каталог модов Modrinth и установка модов в выбранный экземпляр (нужен экземпляр с Fabric, Forge, NeoForge или Quilt).
- Страница «Установленные моды»: список модов экземпляра с названием и версией из самого мода, включение и выключение
  галочкой (файл переименовывается в `.jar.disabled`), удаление, кнопка «Открыть папку».
- Страница «Журнал игры»: вывод запуска, `logs/latest.log` и последний краш-репорт экземпляра, копирование в буфер
  обмена и подсказки о вероятной причине (не хватает памяти, не та Java, нет мода-зависимости, ошибка Mixin,
  драйвер видеокарты и т. д.). После падения игры первая подсказка показывается прямо под кнопкой «Играть».
  Обе страницы открываются и из меню экземпляра (правая кнопка мыши).

### Java

- Лаунчер сам выбирает Java под версию игры (берётся из JSON версии Mojang): 1.20.5 и новее — Java 21,
  1.18–1.20.4 — Java 17, 1.17 — Java 16, старше — Java 8. Сначала проверяется Java, указанная в настройках,
  затем найденные в системе (Program Files, `JAVA_HOME`, runtime официального лаунчера Minecraft), затем
  Java, скачанные самим лаунчером.
- Если подходящей Java нет, она скачивается у Mojang (тот же каталог, что у официального лаунчера; при недоступности —
  через зеркало BMCLAPI) в `~/.material-client/runtime/<сборка>`. Файлы проверяются по SHA-1, прерванная загрузка
  докачивается. Отключается галочкой в настройках («Скачивать нужную Java автоматически»).
- Поле «Путь к javaw.exe» теперь необязательно: пусто — выбор автоматический. Если указанная Java слишком старая,
  лаунчер подберёт другую и напишет об этом в статусе.
- Forge и OptiFine для Minecraft 1.16 и старше не работают на Java 9+ (launchwrapper), поэтому для них всегда
  берётся Java 8, даже если в настройках указана новая.
- **Память**: в настройках лаунчера — значение по умолчанию (пусто = автоматически: 2–4 ГБ для чистой игры,
  до 6 ГБ с модами, но не больше половины оперативной памяти). Для отдельного экземпляра: правая кнопка мыши →
  «Настройки». Значение экземпляра важнее общего.
- **JVM-аргументы**: общие (настройки лаунчера) и для экземпляра, добавляются после аргументов версии, поэтому
  собственный `-Xmx` или `-Dключ=значение` имеет приоритет. Каждый аргумент начинается с `-`; значения с пробелами
  берутся в кавычки, параметры вида `--add-opens` пишутся через `=`.

### Откуда берутся загрузчики

| Загрузчик | Источник |
|-----------|----------|
| Forge | maven.minecraftforge.net (официальный установщик) |
| NeoForge | maven.neoforged.net (официальный установщик) |
| Fabric | meta.fabricmc.net и maven.fabricmc.net |
| Quilt | meta.quiltmc.org и maven.quiltmc.org |
| OptiFine | зеркало BMCLAPI (bmclapi2.bangbang93.com), как у HMCL |

### Если загрузчики не скачиваются (таймаут)

1. Открой настройки лаунчера, раздел «Сеть», и нажми **«Проверить сеть»**: лаунчер покажет, какие сайты отвечают,
   а какие нет (в том числе «соединилось, но данные встали» — так выглядит ограничение скорости у провайдера).
2. Если сайты недоступны, включи VPN для всей системы или впиши свой прокси (`127.0.0.1:7890`,
   `socks5://127.0.0.1:1080`). Лаунчер также использует системный прокси Windows; слово `direct` отключает прокси.
3. Лаунчер сам повторяет запросы с увеличенным ожиданием и переходит на зеркало BMCLAPI, если официальный сайт молчит.

Если OptiFine не скачивается, скачай установщик `OptiFine_<версия>_HD_U_<патч>.jar` с optifine.net и положи в
`~/.material-client/optifine/` — лаунчер возьмёт файл оттуда. Логи установщиков лежат в `~/.material-client/logs/`.

## Пока не реализовано

- OptiFine ставится только на Vanilla (вместе с Forge/Fabric его нужно подключать как мод), а NeoForge
  есть только для Minecraft 1.20.2 и новее.
- Зависимости модов ставятся автоматически только для модов из каталога Modrinth; моды, положенные в папку вручную, не проверяются.
- Вход через Microsoft: после OAuth не выполняются шаги Xbox и Minecraft, токен не сохраняется,
  а в `MicrosoftAuth.kt` нужно указать свой Client ID.
- Старые версии с `assets/virtual` (до 1.7.2): звуки в них не подключаются.

## Перевод

Весь текст лаунчера (интерфейс, статусы, ошибки, подсказки по вылетам) идёт через `tr("русский текст", подстановки)`
из `I18n.kt`: русский текст служит ключом, подстановки пишутся как `{0}`, `{1}`. Английский словарь лежит в
`I18nEn.kt`. Новую строку добавляют так: пишут `tr("...")` в коде и пару «русский → английский» в словарь. Если
перевода нет, на экране остаётся русский текст, а ключ печатается в консоль (`[i18n] нет английского перевода`).
Сообщения, которые начинаются с «Ошибка», «Не удалось», «Укажи» и т. п., показываются красным: в переводе они
должны начинаться с «Error», «Could not», «Specify» и т. д. (список в `I18n.problemPrefixes`).

## Сборка

Требования: JDK 17 и Windows x64 для Windows-пакета. Gradle Wrapper уже в проекте.

```powershell
.\gradlew.bat :composeApp:run
```

### Бета-версия для выкладки

`build_installer.bat` собирает в `composeApp\build\compose\binaries\main\`:

- `app\Material Client\` — портативная версия: папку можно заархивировать и запускать `Material Client.exe` без установки;
- `exe\` и `msi\` — установщики (ставятся в профиль пользователя, без прав администратора, с ярлыком и обновлением
  поверх старой версии). Для них нужен [WiX Toolset 3](https://github.com/wixtoolset/wix3/releases).

Без WiX и без локальной сборки: выложи проект на GitHub и запусти `Build Windows installer` во вкладке Actions
(`.github/workflows/build-windows.yml`): установщики и портативный архив появятся в Artifacts.

Версия лежит в `composeApp/build.gradle.kts` (`version` и `packageVersion`, формат x.y.z). Windows SmartScreen может
предупредить о неподписанном установщике: для беты это нормально, убирает предупреждение только платная подпись кода.

При первой сборке нужен интернет для загрузки зависимостей. Java для самого Minecraft ставить не обязательно:
лаунчер скачает нужную сам.

## Обновление лаунчера

Лаунчер проверяет релизы на GitHub (вкладка «Настройки → О лаунчере») и показывает кнопку «Обновить лаунчер».
Установщик скачивается и запускается сам; благодаря постоянному `upgradeUuid` он обновляет установленную версию.

Чтобы выпустить обновление:
1. Подними версию в трёх местах: `AppInfo.VERSION` (Updater.kt), `version` и `packageVersion` (composeApp/build.gradle.kts).
2. Залей изменения и создай релиз с меткой новее предыдущей (например `v0.3.1-beta`), приложив `.exe`.
3. Репозиторий для проверки задан в `AppInfo.DEFAULT_REPO` (voxydev-tech/Material-Client).
