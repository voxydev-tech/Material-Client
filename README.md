# Material Client

Minecraft-лаунчер для Windows 10/11 в стиле Material 3. Написан на Kotlin и Compose Desktop.
Интерфейс на русском и английском.

## Установка

1. Открой [Releases](https://github.com/voxydev-tech/Material-Client/releases) и скачай последний `.exe`.
2. Запусти установщик. Права администратора не нужны, лаунчер ставится в профиль пользователя.
3. Windows SmartScreen может предупредить о неподписанном установщике: нажми «Подробнее» → «Выполнить в любом случае».

Есть и портативный архив: распакуй и запусти `Material Client.exe`. Java для игры ставить не нужно, лаунчер скачает её сам.

Дальше лаунчер обновляется сам: при выходе новой версии появится баннер «Обновить лаунчер»
(или «Настройки → О лаунчере → Проверить обновления»).

## Возможности

**Экземпляры**
- Создание, дублирование и удаление. У каждого экземпляра своя папка игры в `~/.material-client/instances/`.
- Поиск, сортировка (по созданию, по последнему запуску, по названию, по версии Minecraft).
- Значок, цвет или своя картинка для каждого экземпляра, время игры на карточке.
- Двойной клик запускает игру, правый клик открывает меню экземпляра.
- Импорт сборок Modrinth (`.mrpack`) и экспорт своих.
- Резервные копии миров с восстановлением.

**Игра**
- Версии Minecraft с официальных серверов Mojang, проверка файлов по SHA-1.
- Загрузчики: Forge, NeoForge, Fabric, Quilt и OptiFine.
- Java подбирается и скачивается автоматически под версию игры.
- Память и JVM-аргументы: общие и отдельно для экземпляра.
- Офлайн-аккаунт со скином (нужен мод CustomSkinLoader, лаунчер ставит его кнопкой).
- Кнопка «Закрыть Minecraft» и метка «Запущен» на карточке, пока игра работает.

**Моды, ресурспаки, шейдеры**
- Каталог Modrinth: показываются только файлы под версию и загрузчик выбранного экземпляра.
- Обязательные зависимости (например, Fabric API) ставятся сами.
- Список установленных модов: включить, выключить, удалить, обновить все одной кнопкой.
- Ресурспаки и шейдеры ставятся из того же каталога. Для шейдеров в игре нужен Iris (Fabric и Quilt) или OptiFine.

**Диагностика**
- «Журнал игры»: вывод запуска, `latest.log` и краш-репорт с подсказкой о вероятной причине.
- «Настройки → Сеть → Проверить сеть»: показывает, какие сайты не отвечают.

## Чего пока нет

- Входа через Microsoft: пока только офлайн-аккаунты.
- OptiFine ставится только на Vanilla, а не вместе с Forge или Fabric.
- NeoForge доступен для Minecraft 1.20.2 и новее.
- Версии до 1.7.2: звуки в них не подключаются.

## Если что-то не скачивается

1. «Настройки → Сеть → Проверить сеть»: лаунчер покажет, какие сайты недоступны.
2. Включи VPN для всей системы или впиши свой прокси (`127.0.0.1:7890` или `socks5://127.0.0.1:1080`).
   Системный прокси Windows используется автоматически, слово `direct` отключает прокси.
3. Лаунчер сам повторяет запросы и переходит на зеркало BMCLAPI, если официальный сайт молчит.

Если не скачивается OptiFine, скачай установщик `OptiFine_<версия>_HD_U_<патч>.jar` с optifine.net и положи в
`~/.material-client/optifine/`. Логи установщиков лежат в `~/.material-client/logs/`.

Вывод игры пишется в `launcher-output.log` в папке экземпляра.

## Для разработчиков

Нужны JDK 17 и Windows x64 для Windows-пакета. Gradle Wrapper уже в проекте.

```powershell
.\gradlew.bat :composeApp:run              # запуск
.\gradlew.bat :composeApp:compileKotlin    # проверка, что всё собирается
```

Установщики и портативная версия собираются через `build_installer.bat` (нужен [WiX Toolset 3](https://github.com/wixtoolset/wix3/releases))
или без локальной сборки: вкладка Actions → `Build Windows installer`.

**Выпуск версии**
1. Подними версию в трёх местах: `AppInfo.VERSION` (`Updater.kt`), `version` и `packageVersion` (`composeApp/build.gradle.kts`).
2. Залей изменения и создай релиз GitHub с новой меткой (например `v1.0.0`). Сборка запустится сама и приложит `.exe`, `.msi` и портативный архив.
3. Репозиторий для проверки обновлений задан в `AppInfo.DEFAULT_REPO`.

**Перевод.** Весь текст идёт через `tr("русский текст", подстановки)` из `I18n.kt`: русский текст служит ключом,
подстановки пишутся как `{0}`. Английский словарь лежит в `I18nEn.kt`: нужно добавить пару «русский → английский».
Сообщения, которые начинаются с «Ошибка», «Не удалось», «Укажи» и подобных, показываются красным, поэтому в переводе
они должны начинаться с «Error», «Could not», «Specify» (список в `I18n.problemPrefixes`).

## Шрифт

Основной шрифт — [Onest](https://fonts.google.com/specimen/Onest), лицензия SIL OFL 1.1. Файлы и текст лицензии
лежат в `composeApp/src/main/resources/fonts`.
